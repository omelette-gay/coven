# Object Store

Installs a single-node RustFS S3-compatible object store and creates the requested buckets. Bucket creation uses
the [`rustfs/rc`](https://hub.docker.com/r/rustfs/rc) CLI; its version is pinned in `locals.tf` and kept up to date
by Renovate.

The access and secret keys are generated by the [generated-secret](../generated-secret/) module, so they're kept in
Vault (`object-store/<namespace>/<name>`) and synced into the `<name>-object-store-keys` Secret by External Secrets
Operator, and aren't in Terraform state.
